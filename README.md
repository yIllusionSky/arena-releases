# 怪招英雄

怪招英雄的客户端下载与版本更新。

## 下载

前往 [最新版本](https://github.com/yIllusionSky/arena-releases/releases/latest)，按设备选择安装包：

| 设备 | 文件名结尾 |
| --- | --- |
| Android ARM64 | `android-aarch64.apk` |
| Windows 64 位 | `windows-x86_64.exe` |
| Mac（Apple 芯片） | `darwin-aarch64.dmg` |
| Mac（Intel 芯片） | `darwin-x86_64.dmg` |

首次安装请选择 APK、EXE 或 DMG。`.app.tar.gz`、`.sig` 和 `latest.json` 用于桌面应用更新；`.sha256` 为下载文件校验值。

macOS 当前提供使用 ad-hoc 签名、未经公证的测试包；Windows 安装包暂未使用商业代码签名。Android 的 TapTap 上架和更新以商店实际发布版本为准。
